# راه عدالت — نسخه 3.0

نسخه بازطراحی‌شده بازی آموزشی «راه عدالت» برای آموزش قانون آیین دادرسی مدنی در قالب پرونده و بازی.

## ویژگی‌های نسخه 3
- دفتر وکیل به‌عنوان محیط اصلی و قابل تعامل.
- لمس مستقیم اشیای واقعی محیط: قفسه کتابخانه، بایگانی، مانیتور، کتاب قانون و پرونده روی میز.
- حذف دکمه‌های بزرگ و زمخت روی تصویر دفتر.
- بازگشت بزرگ در بالا-چپ و تنظیمات بزرگ در بالا-راست.
- پنج پرونده با پنج داستان مستقل و چهار گام روایی برای هر پرونده.
- شخصیت‌های PNG شفاف و نمایش کامل کاراکتر در صحنه.
- آموزش اصطلاحات حقوقی در دل داستان.
- آزمون تعاملی؛ هیچ گزینه‌ای قبل از انتخاب سبز نیست و پاسخ صحیح بین گزینه‌ها جابه‌جا می‌شود.
- توضیح آموزشی برای پاسخ درست یا غلط.
- نمایش متن فارسی با چیدمان راست‌به‌چپ و محدوده امن برای موبایل.
- ذخیره پیشرفت پرونده‌های تکمیل‌شده.
- بخش کتاب قانون، بایگانی و پیشرفت.
- موسیقی مراحل با کنترل از تنظیمات.
- Workflow آماده GitHub Actions با Android SDK setup v4.
